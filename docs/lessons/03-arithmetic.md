# Урок 3. Арифметика и выражения

## Четыре действия и остаток

```hla
extern printf(fmt, ...)

fn main() {
    let a = 17, b = 5
    printf("%ld + %ld = %ld\n", a, b, a + b)
    printf("%ld - %ld = %ld\n", a, b, a - b)
    printf("%ld * %ld = %ld\n", a, b, a * b)
    printf("%ld / %ld = %ld\n", a, b, a / b)   // деление целое: дробная часть отбрасывается
    printf("%ld %% %ld = %ld\n", a, b, a % b)  // остаток от деления; %% печатает знак %
}
```

```text
17 + 5 = 22
17 - 5 = 12
17 * 5 = 85
17 / 5 = 3
17 % 5 = 2
```

Деление округляет **к нулю**, а остаток имеет знак делимого — как в C:

```hla
extern printf(fmt, ...)

fn main() {
    let a = -17
    printf("%ld / 5 = %ld, остаток %ld\n", a, a / 5, a % 5)
}
```

```text
-17 / 5 = -3, остаток -2
```

## Выражения любой сложности

Выражение можно писать как в обычной математике, со скобками. Транслятор сам разложит его на
команды процессора и, если нужно, использует временные регистры.

```hla
extern printf(fmt, ...)

fn main() {
    let celsius = 36
    let fahrenheit = celsius * 9 / 5 + 32
    printf("%ld°C = %ld°F\n", celsius, fahrenheit)

    let x = 3, y = 4
    let r = (x + y) * (x - y) + x * x * y
    printf("(3+4)*(3-4) + 3*3*4 = %ld\n", r)
}
```

```text
36°C = 96°F
(3+4)*(3-4) + 3*3*4 = 29
```

## Сокращённое присваивание

Запись `a += 5` — то же, что `a = a + 5`. Так можно с любым оператором. `i++` и `i--` прибавляют и
вычитают единицу.

```hla
extern printf(fmt, ...)

fn main() {
    let n = 10
    n += 5       // 15
    n *= 2       // 30
    n -= 4       // 26
    n /= 3       // 8
    n %= 5       // 3
    n++          // 4
    printf("n = %ld\n", n)
}
```

```text
n = 4
```

## Пример: цифры числа

Деление на 10 отбрасывает последнюю цифру, остаток от деления на 10 — это и есть последняя цифра.

```hla
extern printf(fmt, ...)

fn main() {
    let number = 2026
    let units = number % 10
    let tens = number / 10 % 10
    let hundreds = number / 100 % 10
    let thousands = number / 1000
    printf("%ld: тысячи=%ld сотни=%ld десятки=%ld единицы=%ld\n", number, thousands, hundreds, tens, units)
}
```

```text
2026: тысячи=2 сотни=0 десятки=2 единицы=6
```

## Биты

Число в регистре — это 64 бита (нулей и единиц). С битами работают такие операторы:

| оператор | смысл | пример (в двоичном виде) |
|---|---|---|
| `a & b` | И: 1, где обе единицы | `1100 & 1010 = 1000` |
| `a \| b` | ИЛИ: 1, где хоть одна единица | `1100 \| 1010 = 1110` |
| `a ^ b` | исключающее ИЛИ: 1, где биты разные | `1100 ^ 1010 = 0110` |
| `~a` | НЕ: все биты наоборот | |
| `a << n` | сдвиг влево на n бит (умножение на 2ⁿ) | `0011 << 2 = 1100` |
| `a >> n` | сдвиг вправо (деление на 2ⁿ) | `1100 >> 2 = 0011` |
| `a >>> n` | сдвиг вправо, всегда заполняя слева нулями | |

```hla
extern printf(fmt, ...)

const FLAG_READ = 1 << 0     // 0b001
const FLAG_WRITE = 1 << 1    // 0b010
const FLAG_EXEC = 1 << 2     // 0b100

fn main() {
    let flags = FLAG_READ | FLAG_EXEC          // включить два флага
    printf("flags = %lx\n", flags)
    flags |= FLAG_WRITE                         // включить ещё один
    flags &= ~FLAG_EXEC                         // выключить EXEC
    printf("flags = %lx\n", flags)
    printf("можно писать: %ld\n", (flags & FLAG_WRITE) != 0)
    printf("0xF0 >> 4 = %lx, 1 << 10 = %ld\n", 0xF0 >> 4, 1 << 10)
}
```

```text
flags = 5
flags = 3
можно писать: 1
0xF0 >> 4 = f, 1 << 10 = 1024
```

Сравнение `(flags & FLAG_WRITE) != 0` даёт 1, если условие истинно, и 0, если ложно.

## Порядок операций

Умножение выполняется раньше сложения, как в школе. Полная таблица:

| сначала | операторы |
|---|---|
| 1 | унарные `-` `~` `!` |
| 2 | `*` `/` `%` `<<` `>>` `>>>` `&` |
| 3 | `+` `-` `\|` `^` |
| 4 | сравнения `==` `!=` `<` `<=` `>` `>=` |
| 5 | `&&` |
| 6 | `\|\|` |

Обратите внимание: битовое `&` сильнее сравнения. Поэтому `x & 1 == 0` означает `(x & 1) == 0` —
«x чётное», как и хотелось. (В языке C это частая ошибка, в HLA64 её нет.) Если сомневаетесь —
ставьте скобки.

## Переполнение

Регистр не бесконечен. Если результат не помещается в 64 бита, лишние старшие биты просто
отбрасываются, и число «заворачивается»:

```hla
extern printf(fmt, ...)

const MAX = 0x7FFFFFFFFFFFFFFF   // самое большое знаковое 64-битное число

fn main() {
    let big = MAX
    printf("%ld\n", big)
    big += 1
    printf("%ld\n", big)          // стало самым маленьким отрицательным
}
```

```text
9223372036854775807
-9223372036854775808
```

## Знаковые и беззнаковые числа

Одни и те же 64 бита можно читать двумя способами. Например, все единицы — это −1, если число
**знаковое**, и 18 446 744 073 709 551 615, если **беззнаковое**. По умолчанию переменные знаковые.
Слово `unsigned` меняет смысл деления, сдвига `>>` и сравнений:

```hla
extern printf(fmt, ...)

fn main() {
    let s = -16                 // знаковая
    let unsigned u = -16        // те же биты, но беззнаковая
    printf("знаковое:    %ld / 2 = %ld,  >> 2 = %ld\n", s, s / 2, s >> 2)
    printf("беззнаковое: %lu / 2 = %lu,  >> 2 = %lu\n", u, u / 2, u >> 2)
    printf("s > 0: %ld,  u > 0: %ld\n", s > 0, u > 0)
}
```

```text
знаковое:    -16 / 2 = -8,  >> 2 = -4
беззнаковое: 18446744073709551600 / 2 = 9223372036854775800,  >> 2 = 4611686018427387900
s > 0: 0,  u > 0: 1
```

`%lu` печатает число как беззнаковое.

## 32 бита: регистры `w`

Если выражение записывается в `w`-регистр, оно считается в 32 битах. Это удобно, когда работаете
с 32-битными данными (например, из массива `i32`, урок 7). Для печати 32-битного числа используйте `%d`.

```hla
extern printf(fmt, ...)

fn main() {
    w9 = 0xFFFFFFFF          // все 32 бита — единицы
    w9 = w9 + 1              // в 32 битах это переполнение: получается 0
    x10 = 0xFFFFFFFF
    x10 = x10 + 1            // в 64 битах места хватает
    printf("w9 = %d, x10 = %ld\n", w9, x10)
}
```

```text
w9 = 0, x10 = 4294967296
```

## Полезные встроенные функции

```hla
extern printf(fmt, ...)

fn main() {
    let a = -7, b = 3
    printf("min=%ld max=%ld abs=%ld\n", min(a, b), max(a, b), abs(a))
    printf("clz(1)=%ld — сколько нулей перед первой единицей\n", clz(1))
}
```

```text
min=-7 max=3 abs=7
clz(1)=63 — сколько нулей перед первой единицей
```

## Как транслятор выбирает команды

Транслятор старается подобрать короткие команды. Несколько примеров того, что получается:

| HLA64 | ассемблер |
|---|---|
| `a = b + 5` | `add x19, x20, #5` |
| `a = b * 8` | `lsl x19, x20, #3` (сдвиг вместо умножения) |
| `a = b + c * d` | `madd x19, x21, x22, x20` (умножение со сложением за одну команду) |
| `a = b & ~c` | `bic x19, x20, x21` |
| `a = 0x123456789` | `movz` + `movk` — большое число собирается по 16 бит |

Можно проверить сами: `node src/cli.ts compile файл.hla`.
