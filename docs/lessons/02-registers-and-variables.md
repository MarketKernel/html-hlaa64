# Урок 2. Регистры и переменные

## Что такое регистр

Процессор считает не прямо в памяти, а в **регистрах** — маленьких ячейках внутри себя.
У AArch64 их 31 основной: `x0`, `x1`, … `x30`. Каждый вмещает одно 64-битное целое число,
то есть примерно от −9.2·10¹⁸ до 9.2·10¹⁸.

Регистр можно использовать как переменную: положить в него число, сложить, напечатать.

```hla
extern printf(fmt, ...)

fn main() {
    x9 = 42
    printf("в регистре x9 лежит %ld\n", x9)
}
```

```text
в регистре x9 лежит 42
```

`printf` — функция печати из языка C. Первый аргумент — строка-шаблон, в которой `%ld` означает
«сюда подставить целое число». Запись `printf(fmt, ...)` в `extern` говорит транслятору, что после
шаблона может идти любое количество аргументов (у Apple их нужно передавать особым образом, и
транслятор сделает это сам).

## Имена для регистров

Писать `x9`, `x10`, `x11` неудобно: через пять строк уже не вспомнишь, что где лежит. Поэтому
регистру можно дать **имя** (псевдоним):

```hla
extern printf(fmt, ...)

fn main() {
    alias apples = x9
    alias pears = x10
    apples = 5
    pears = 7
    x11 = apples + pears
    printf("всего фруктов: %ld\n", x11)
}
```

```text
всего фруктов: 12
```

`alias` не создаёт ничего нового: `apples` — это просто второе имя регистра `x9`.

Короче то же самое записывается через `let` — имя, регистр и начальное значение сразу:

```hla
extern printf(fmt, ...)

fn main() {
    let width: x9 = 8
    let height: x10 = 3
    let area: x11 = width * height
    printf("%ld x %ld = %ld\n", width, height, area)
}
```

```text
8 x 3 = 24
```

## Пусть регистр выберет транслятор

Чаще всего неважно, в каком именно регистре лежит переменная. Тогда регистр можно не указывать:

```hla
extern printf(fmt, ...)

fn main() {
    let a = 10, b = 20       // несколько переменных через запятую
    let sum = a + b
    printf("a=%ld b=%ld sum=%ld\n", a, b, sum)
}
```

```text
a=10 b=20 sum=30
```

Транслятор сам подберёт свободные регистры из `x19 … x28` и напишет в ассемблере комментарий,
что куда попало:

```asm
// a -> x19
    mov x19, #10
// b -> x20
    mov x20, #20
// sum -> x21
    add x21, x19, x20
```

Почему именно `x19 … x28`? Это **сохраняемые** регистры: любая функция, которую мы вызываем
(например, `printf`), обязана вернуть их такими, какими получила. Значит, значения в них переживают
вызовы. Об этом подробнее — в уроке про функции.

## Какие бывают регистры

| регистры | для чего |
|---|---|
| `x0 … x7` | аргументы функций и результат (`x0`); **портятся** при вызове функции |
| `x8 … x15` | временные, тоже **портятся** при вызове функций |
| `x16`, `x17` | заняты транслятором для промежуточных вычислений — не трогайте |
| `x18` | зарезервирован macOS — не используйте |
| `x19 … x28` | сохраняемые: переживают вызовы функций |
| `x29` (`fp`), `x30` (`lr`) | служебные: кадр функции и адрес возврата |
| `sp` | указатель стека |
| `xzr` | всегда ноль |

Простое правило для начала: **объявляйте переменные через `let` без регистра**, а конкретные
регистры (`x0`, `x9`, …) берите только для коротких временных значений между двумя строками.

## Половинки регистров: `w`

У каждого `x`-регистра есть младшая 32-битная половина с именем `w`: `w9` — это младшие 32 бита
`x9`. Запись в `w9` обнуляет старшие 32 бита. Подробнее о 32 и 64 битах — в следующем уроке.

```hla
extern printf(fmt, ...)

fn main() {
    x9 = 0x1122334455667788
    printf("x9 = %lx\n", x9)
    w9 = 5                      // пишем только в нижнюю половину...
    printf("x9 = %lx\n", x9)    // ...а верхняя обнулилась
}
```

```text
x9 = 1122334455667788
x9 = 5
```

`%lx` печатает число в шестнадцатеричном виде.

## Запись чисел

```hla
extern printf(fmt, ...)

fn main() {
    let dec = 1_000_000         // подчёркивания для удобства чтения
    let hex = 0xFF              // шестнадцатеричное
    let bin = 0b1010            // двоичное
    let oct = 0o17              // восьмеричное
    let ch = 'A'                // код символа
    let neg = -42
    printf("%ld %ld %ld %ld %ld %ld\n", dec, hex, bin, oct, ch, neg)
    printf("символ: %c\n", ch)  // %c печатает число как символ
}
```

```text
1000000 255 10 15 65 -42
символ: A
```

## Константы

Если число никогда не меняется, дайте ему имя через `const`. Константа существует только во время
трансляции: в программе вместо неё окажется само число, регистр не тратится.

```hla
extern printf(fmt, ...)

const SECONDS_PER_MINUTE = 60
const MINUTES_PER_HOUR = 60
const SECONDS_PER_DAY = 24 * MINUTES_PER_HOUR * SECONDS_PER_MINUTE

fn main() {
    let days = 7
    printf("в неделе %ld секунд\n", days * SECONDS_PER_DAY)
}
```

```text
в неделе 604800 секунд
```

`24 * 60 * 60` транслятор посчитал сам — в программе будет просто `86400`.

## Где живёт переменная

Переменная, объявленная внутри `{ }`, существует до закрывающей скобки. После неё имя исчезает,
а регистр освобождается для других переменных.

```hla
extern printf(fmt, ...)

fn main() {
    let a = 1
    {
        let b = 2                         // b видна только внутри этих скобок
        printf("внутри: a=%ld b=%ld\n", a, b)
    }
    let c = 3                             // c может получить тот же регистр, что был у b
    printf("снаружи: a=%ld c=%ld\n", a, c)
}
```

```text
внутри: a=1 b=2
снаружи: a=1 c=3
```

fn main() {

a=2 b=1
