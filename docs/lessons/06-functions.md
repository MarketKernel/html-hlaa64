# Урок 6. Функции

Функция — именованный кусок программы, который можно вызывать много раз.

## Объявление и вызов

```hla
extern puts

fn greet() {
    puts("Привет из функции!")
}

fn main() {
    greet()
    greet()
}
```

```text
Привет из функции!
Привет из функции!
```

Порядок объявления не важен: функцию можно вызвать выше того места, где она написана.

## Параметры и результат

Параметры перечисляются в скобках. Результат возвращается командой `return`.

```hla
extern printf(fmt, ...)

fn square(n) {
    return n * n
}

fn add3(a, b, c) {
    return a + b + c
}

fn main() {
    printf("square(7) = %ld\n", square(7))
    let s = add3(1, 2, 3)
    printf("add3(1, 2, 3) = %ld\n", s)
    printf("вместе: %ld\n", square(add3(1, 1, 1)))
}
```

```text
square(7) = 49
add3(1, 2, 3) = 6
вместе: 9
```

Как это устроено. По соглашению Apple ARM64 (его соблюдают и C, и HLA64):

- аргументы передаются в регистрах `x0, x1, x2, … x7` по порядку;
- результат возвращается в `x0`.

Поэтому параметр без указания регистра — это просто **имя для регистра**: в `add3` имя `a` означает
`x0`, `b` — `x1`, `c` — `x2`. А `return a + b + c` кладёт сумму в `x0`.

## Ранний `return`

`return` можно поставить в любом месте — функция сразу завершится.

```hla
extern printf(fmt, ...)

fn sign(x) {
    if x > 0 { return 1 }
    if x < 0 { return -1 }
    return 0
}

fn main() {
    printf("%ld %ld %ld\n", sign(-5), sign(0), sign(12))
}
```

```text
-1 0 1
```

## Главная ловушка: регистры портятся при вызове

Вызванная функция имеет право изменить регистры `x0 … x17` — она пользуется ими для своих дел.
Значит, после **любого** вызова значения в этих регистрах могут оказаться другими. А параметры
функции лежат именно там. Вот так писать **нельзя**:

```hla
fn show_twice(n) {               // n — это x0
    printf("%ld\n", n)
    printf("%ld\n", n)           // ОШИБКА: первый printf уже испортил x0
}
```

Есть два способа это исправить.

**1. Скопировать параметр в «долгую» переменную.** Переменные `let` без регистра живут в
сохраняемых регистрах `x19 … x28`, а их любая функция обязана вернуть нетронутыми:

```hla
extern printf(fmt, ...)

fn show_twice(n) {
    let keep = n                 // keep попадёт в x19 — переживёт вызовы
    printf("%ld\n", keep)
    printf("%ld\n", keep)
}

fn main() {
    show_twice(42)
}
```

```text
42
42
```

**2. Сразу объявить параметр «долгим»**: `n: auto` — транслятор при входе в функцию скопирует
`x0` в свободный сохраняемый регистр.

```hla
extern printf(fmt, ...)

fn show_twice(n: auto) {
    printf("%ld\n", n)
    printf("%ld\n", n)
}

fn main() {
    show_twice(7)
}
```

```text
7
7
```

А сохранять и восстанавливать `x19 … x28` в своей функции не нужно — транслятор видит, какие из них
вы используете, и сам добавляет это в начало и конец функции.

Ту же ловушку транслятор умеет замечать в выражениях: если написать `f(x) + a`, где `a` лежит в
`x0 … x17`, он выдаст ошибку с объяснением.

## Рекурсия

Функция может вызывать сама себя. Факториал: `n! = n · (n−1)!`, и `1! = 1`.

```hla
extern printf(fmt, ...)

fn factorial(n: auto) {          // auto: n нужен после рекурсивного вызова
    if n <= 1 { return 1 }
    let rest = factorial(n - 1)
    return n * rest
}

fn main() {
    for k in 1..=10 {
        printf("%ld! = %ld\n", k, factorial(k))
    }
}
```

```text
1! = 1
2! = 2
3! = 6
4! = 24
5! = 120
6! = 720
7! = 5040
8! = 40320
9! = 362880
10! = 3628800
```

Числа Фибоначчи — два рекурсивных вызова:

```hla
extern printf(fmt, ...)

fn fib(n: auto) {
    if n < 2 { return n }
    let a = fib(n - 1)           // a в сохраняемом регистре — переживёт второй вызов
    let b = fib(n - 2)
    return a + b
}

fn main() {
    printf("fib(25) = %ld\n", fib(25))
}
```

```text
fib(25) = 75025
```

Каждый вызов получает свой **кадр** в стеке, где сохраняются его регистры, поэтому у каждого
уровня рекурсии свои `n`, `a` и `b`.

## Алгоритм Евклида

Наибольший общий делитель — классический пример функции с циклом:

```hla
extern printf(fmt, ...)

fn gcd(a, b) {
    while b != 0 {
        let r: x9 = a % b        // x9 можно: внутри цикла нет вызовов
        a = b
        b = r
    }
    return a
}

fn main() {
    printf("gcd(1071, 462) = %ld\n", gcd(1071, 462))
    printf("gcd(17, 5) = %ld\n", gcd(17, 5))
}
```

```text
gcd(1071, 462) = 21
gcd(17, 5) = 1
```

Здесь параметры `a` и `b` (то есть `x0` и `x1`) использовать безопасно: внутри функции нет вызовов,
портить их некому.

## Параметр в выбранном регистре

Можно указать регистр явно: `fn f(n: x20)` — при входе значение будет скопировано из `x0` в `x20`.
Функции, которые ничего не возвращают, можно завершить пустым `return`.

## Что делает процессор

Вызов — команда `bl` («branch with link»): она прыгает на функцию и записывает адрес возврата
в регистр `x30`. Возврат — команда `ret`, которая прыгает по адресу из `x30`. Поскольку функция
сама может вызвать другую (и `x30` перезапишется), транслятор в начале каждой функции сохраняет
`x29` и `x30` в стек, а в конце восстанавливает. Вот что получилось для `factorial`:

```asm
_factorial:
    stp x29, x30, [sp, #-16]!   // сохранить fp и адрес возврата
    mov x29, sp
    sub sp, sp, #16             // место для сохраняемых регистров
    stp x19, x20, [sp]          // сохранить x19, x20 вызывающей стороны
    mov x19, x0                 // n: auto -> x19
    cmp x19, #1
    b.gt Lfactorial.endif0
    mov x0, #1
    b Lfactorial.ret
Lfactorial.endif0:
    sub x0, x19, #1             // аргумент n - 1
    bl _factorial               // рекурсивный вызов
    mov x20, x0                 // rest
    mul x0, x19, x20            // return n * rest
Lfactorial.ret:
    sub sp, x29, #16
    ldp x19, x20, [sp]          // вернуть x19, x20 как было
    mov sp, x29
    ldp x29, x30, [sp], #16
    ret
```

## Упражнения

1. Напишите `power(base, exp)` — возведение в степень циклом.
2. Напишите рекурсивную `sum_digits(n)`: сумма цифр — это `n % 10 + sum_digits(n / 10)`.

<summary>Решение упражнения 2</summary>

```hla
extern printf(fmt, ...)

fn sum_digits(n: auto) {
    if n == 0 { return 0 }
    let rest = sum_digits(n / 10)
    return n % 10 + rest
}

fn main() {
    printf("%ld\n", sum_digits(987654321))
}
```

```text
45
```
