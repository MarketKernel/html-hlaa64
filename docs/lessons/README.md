# Уроки HLA64

Курс для тех, кто впервые видит HLA64 — и, возможно, ассемблер вообще. Начинаем с «Hello, world»
и шаг за шагом доходим до структур, указателей, плавающей точки и встроенного ассемблера.
Каждый урок — это примеры, которые можно запустить, и объяснение, что происходит внутри процессора.

## Что такое HLA64 в двух словах

Процессор Apple M1/M2/M3/M4 (архитектура **AArch64**, она же ARM64) умеет выполнять простые команды:
«сложи два регистра», «загрузи число из памяти», «перейди на другую команду». Программа на ассемблере —
это список таких команд. Писать её вручную долго: даже простой цикл занимает пять-шесть строк.

HLA64 оставляет вас рядом с процессором — вы работаете с **регистрами** и **памятью** напрямую, —
но позволяет писать `for`, `if`, `a = b + c * 4` и `printf(...)`. Транслятор превращает это
в обычный ассемблер, а встроенный ассемблер — в настоящую программу для macOS.

## Как запускать примеры

Есть три способа, выберите удобный.

**1. В браузере.** Откройте страницу https://marketkernel.github.io/html-hlaa64/ или соберите её
сами (`npm run build:web`) и откройте файл `dist/hla64.html` — он работает без интернета. Вставьте программу
в левое окно и нажмите **Run** — программа выполнится во встроенном эмуляторе процессора, а справа
можно посмотреть сгенерированный ассемблер и машинный код.

**2. В терминале macOS.** Сохраните программу в файл, например `hello.hla`, и выполните:

```sh
node src/cli.ts run hello.hla        # перевести, собрать и запустить
node src/cli.ts compile hello.hla    # показать, какой ассемблер получился
node src/cli.ts build hello.hla -o hello && ./hello   # собрать исполняемый файл
```

**3. В эмуляторе из терминала** (работает и не на Mac): `node src/cli.ts emu hello.hla`.

упражнения — попробуйте решить их сами, а потом сверьтесь с решением.

Полный справочник языка без объяснений — в [../language.md](../language.md). Там же — то, чего нет
в уроках: программа из [нескольких файлов](../language.md#несколько-файлов) (`include`) и
[чтение и запись файлов](../language.md#файлы-stdfilehla) одинаковыми функциями на macOS и Windows
(`include "std/file.hla"`).
